Problem

Industrial Fault Detection at Scale

Manufacturing facilities generate massive streams of multimodal data — SCADA sensor readings, camera feeds of equipment, and unstructured maintenance records. These exist in silos, requiring manual correlation by engineers who can miss critical failure patterns. Manual review is slow (hours to days), expensive, and subject to human error.

Approach

Graph RAG with LangGraph Orchestration

Rather than a monolithic model, I designed a Graph RAG architecture where different modalities are processed by specialized sub-systems and unified through a knowledge graph. LangGraph manages the state machine, routing queries to the appropriate processing nodes based on input type and fault type.

Implementation

Production Pipeline on AWS EKS

FastAPI serves the inference API with async request handling. LangGraph orchestrates the multi-step reasoning pipeline. All components are containerized with Docker and orchestrated on AWS EKS with auto-scaling based on queue depth. GitHub Actions handles the full CI/CD pipeline with automated testing, image building, and zero-downtime rolling deployments.

Challenges

Cross-Modal Latency & Consistency

The hardest challenge was keeping total inference latency under 300ms while coordinating three independent processing pipelines. Solved with async parallel execution in LangGraph nodes, shared PostgreSQL connection pool with pgBouncer, and careful batching of HuggingFace embedding calls to minimize GPU round-trips.

Results

230ms Latency · 38% Fault Reduction · 90% F1

Achieved 230ms average inference latency (target was 300ms), 38% reduction in manual fault-flagging workload, and 90% F1-score on the fault classification benchmark. Zero-downtime deployments enabled weekly model updates without service interruption.

Problem

Compliance Audits are Slow, Expensive, and Miss Gaps

Enterprise compliance teams spend weeks reviewing regulatory documents, listening to board meeting recordings, and cross-referencing audit tables. Cross-regulation gaps (e.g., a GDPR Article 32 requirement missed in an SOC-2 audit table) are easily overlooked. The cost and latency of manual review creates business risk.

Approach

4-Agent LangGraph System with Hybrid RAG

Designed a specialized 4-agent architecture: a Router agent that classifies input and selects the appropriate compliance agent (GDPR, SOC-2, ISO-27001, SEC). Each compliance agent uses LlamaIndex + hybrid RAG (dense embeddings + BM25 + cross-encoder reranking) to retrieve relevant regulation sections and compare against the audit content.

Implementation

Celery Task Queue + GCP Cloud Run Deployment

Compliance analysis is computationally expensive. Celery + Redis handles asynchronous task processing so users receive immediate acknowledgment while analysis runs in the background. FastAPI serves the API layer. GCP Cloud Run provides auto-scaling serverless deployment that handles variable load spikes during quarterly compliance cycles.

Challenges

Hallucination Control in Compliance Context

In compliance, a false negative (missing a real gap) is a legal risk. The biggest challenge was ensuring the system doesn't hallucinate compliance gaps or miss real ones. Solved with strict RAGAS faithfulness evaluation during development, conservative retrieval thresholds, and citation tracking so every generated gap claim links to specific regulation text.

Results

F1 0.87 · RAGAS 0.91 · 96.4% Routing Accuracy

Achieved strong evaluation metrics: 0.87 F1 for gap detection, 0.91 RAGAS faithfulness (retrieved content truly supports claims), and 96.4% agent routing accuracy. The system reduced manual compliance review time from days to minutes for standard framework audits.

Problem

Fitness Apps Lack Real Intelligence

Most fitness apps are glorified timers. They count sets and reps by user input, not by actually tracking movement. Without real-time form feedback, users develop incorrect movement patterns, leading to injury and plateau. Personal trainers cost $50–150/hr and aren't accessible to most users.

Approach

On-Device Pose Estimation for Privacy-First AI

Used Google ML Kit's pose estimation (33 body keypoints at 30fps) for all movement analysis. By keeping inference on-device, no video data ever leaves the phone — crucial for health apps. Joint angles computed from keypoint coordinates determine rep count state machine transitions and form quality scores.

Implementation

Flutter + FastAPI + Firebase Stack

Flutter handles the cross-platform mobile layer with custom paint for pose overlay visualization. FastAPI backend manages user profiles, workout history, and progress analytics. Firebase provides real-time sync for workout sessions and handles authentication. All health data is AES-256 encrypted before leaving the device.

Challenges

Accuracy Across Diverse Body Types & Camera Angles

The core challenge was achieving consistent accuracy across different body types, clothing, and camera placement angles. Addressed by training the angle thresholds on a diverse dataset, adding adaptive calibration during the first rep of each set, and implementing confidence-weighted smoothing to filter noise from pose keypoints.

Results

97% Accuracy · Sub-140ms API · 91% Test Coverage

Achieved ~97% rep-counting accuracy across 8 exercise types on mobile devices, sub-140ms p95 API response times, and 91% unit/integration test coverage with TDD best practices. Zero video data ever leaves the user's device, providing a privacy-first AI training experience.
